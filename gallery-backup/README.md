# Galería archivada

La galería de artistas se ha retirado temporalmente de la web pública mientras se incorporan nuevos bailarines.

- `images/` conserva las 17 fotografías originales de la galería.
- `backgrounds/festival-crowd-background.jpg` conserva el fondo que acompañaba a la sección.
- La última versión pública que incluía la sección corresponde al commit `0bb6f7d`.

Cuando el contenido esté completo, la galería puede restaurarse tomando como referencia ese commit y volviendo a integrar el bloque en `src/main.tsx` junto con sus estilos en `src/modern.css`.
