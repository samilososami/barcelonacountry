# Propuestas gráficas

Archivo de las imágenes y variantes preparadas para Barcelona Country Festival. Se conservan las versiones anteriores para comparar y los paquetes ZIP entregables.

- `xavi-country-images-2026-10-21/`: propuestas de imágenes de ambiente country, versiones PNG y copias preparadas para correo.
- `logos-xavi-2026-10-30/`: emblema completo y variantes de la estrella con relleno dorado.
- `logos-barcelona-conceptos-2026-10-30/`: Sagrada Familia, skyline, mosaico modernista y Eixample.
- `logos-barcelona-conceptos-2026-10-31/`: revisiones de la propuesta de la Sagrada Familia, con sus prompts.

Estos archivos no sustituyen los recursos de `public/assets/`. Su inclusión en Git no implica su selección como diseño definitivo ni su integración en la web.
